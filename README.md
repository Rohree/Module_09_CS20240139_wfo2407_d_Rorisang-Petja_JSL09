# Crypto Dashboard

Welcome to the **Crypto Dashboard** – a personal project designed to track the latest cryptocurrency data, trends, and analytics, all in one place.

## 🚀 Live Demo

Check out the live dashboard [here](https://cryptoodashboardo.netlify.app/).

## 📋 Features

- **Real-time Cryptocurrency Prices**: Stay updated with the latest prices for popular cryptocurrencies.
- **Market Trends**: Visualize price movements and trends over different time periods.
- **Responsive Design**: Optimized for both desktop and mobile views.
- **Clean User Interface**: Minimalist and intuitive design for seamless navigation.

## 🛠️ Technologies Used

- **React**: Frontend framework for building the dynamic interface.
- **Tailwind CSS**: Styling the dashboard with custom, responsive design elements.
- **CoinGecko API**: Fetching real-time cryptocurrency data.
- **Netlify**: Hosting the live version of the dashboard.

## 📦 Installation

To run this project locally, follow these steps:

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/your-repo.git
2. Navigate to the project directory:

    ```bash
    cd your-repo
    ```

3. Install dependencies:

    ```bash
    npm install
    ```

4. Start the development server:

    ```bash
    npm start
    ```

The app should now be running at `http://localhost:3000/`.
